### 3.2 High — recommended

- 🟠 `submit.py:62-63,75` — `create_task` receives `plan["platform"]` but steps come from `plan["content_type"]`; a `threads` row can carry `threads_video` steps → wrong executor. Fix: pass `plan["content_type"]`.
- 🟠 `slugify.py:23` — `(slug + video_id)[:SLUG_MAX_LEN]` can cut `_v_<id>` mid-suffix → distinct videos collide. Fix: truncate base slug to `SLUG_MAX_LEN - len(video_id)` before appending.
- 🟠 `bulk.py:55` — default `submit_fn` is `submit_url`, so `ingest_playlist()`/`bulk_import()` called outside the MCP send YouTube through the full per-video pipeline instead of deferred batch. Fix: default to `submit_routed`.
- 🟠 `watch_source.py:195,268` — default `submit_fn` is `submit_url`; the cron poller doesn't override it, so watched videos bypass the deferred batch. Fix: default `submit_routed`.
- 🟠 `youtube.py:1253` + `bunny_stream.py:451` — `_update_note_*` rewrites `source_files:` even when `uploaded` is empty, dropping URLs. Fix: `if not uploaded: return`.
- 🟠 `video_common.py:33-39` — `fetch_transcript` doesn't normalize segment `time`→`start`/`end`; speaker summaries render `(00:00)`. Fix: normalize after `mc cp`.
- 🟠 `batch_ingest.py:122-127` — `batch_transcribe.py` `returncode` ignored → failed Modal still enters upload/dispatch. Fix: check returncode before step 3.
- 🟠 `batch_transcribe.py:75-106` — failed `ffmpeg` still appends name; non-zero Modal exit still merges stale JSON. Fix: early-return on non-zero.
- 🟠 `batch_ingest.py:141-146` — `dispatch_synthesize` + `update_ingest_status` not atomic; crash → duplicate synthesize task. Fix: mark intermediate status before dispatch.
- 🟠 `server.py:216-236` — `run_batch` checks `is_locked()` then spawns (TOCTOU); two calls both report `started`. Fix: parent `acquire()` before `Popen`.
- 🟠 `server.py:114-118` — `resume_task("")` maps to `LIKE '%'` → resumes **all** paused tasks. Fix: require non-empty reason.

### 3.3 Medium

- 🟡 `archival.py:40` — `append_note_tags` matches `^tags:` but prompts emit indented `  tags:` → user tags silently dropped. Fix: `^[ \t]*tags:`.
- 🟡 `archival.py:40-42` — no-ops when note has no `tags:` line. Fix: insert before closing `---`.
- 🟡 `archival.py:133` vs `45` — `upload_file_to_minio` hardcodes Tailscale host; `write_source_files_block` uses `MINIO_TAILSCALE_BASE`. Fix: reuse the constant.

- 🟡 `archival.py:68` — lookahead `(?=\n\w|\Z)` can swallow body when next line is `---`. Fix: `(?=\n---|\n[a-zA-Z_]+:|\Z)`.
- 🟡 `archival.py:59-65` — unmapped extensions become YAML keys (`txt`, `md`, `epub`) instead of ADR kinds. Fix: extend suffix map.
- 🟡 `detection.py:428` — `dedup_check` greps URL as regex (no `-F`); URL metachars break matching. Fix: `grep -F`.
- 🟡 `detection.py:67,150` — Threads fetch hardcodes `/root/kb-agent/cookies/`; `_check_threads` also checks Hermes path. Fix: one resolver.
- 🟡 `pipelines.py` — no `mega_video` entry; falls through to `mega` (book-archive steps). Fix: add `mega_video`.
- 🟡 `youtube.py:1178-1184` — synthesize-only path never writes `_metadata.json`, so the 100 chars/min density gate is skipped. Fix: fetch/write metadata in `fetch_transcript`.
- 🟡 `youtube.py:168` — `float(parts[2])` throws on yt-dlp `NA`. Fix: default `0.0`.
- 🟡 `youtube.py:1064` — pass-2 prompt still says "leave minio: for later" while `source_files` is populated. Fix: drop the instruction.
